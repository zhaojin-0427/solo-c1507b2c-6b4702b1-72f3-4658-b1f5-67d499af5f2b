# 套色木刻工作台

本机 Web 工作台,用于套色木刻的**分版、试印校准与版序比较**。

- 后端:Python Flask + SQLite(数据存于 `woodcut.db`)
- 前端:原生 HTML / CSS / JavaScript + Canvas,无任何构建步骤

## 运行

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
# 打开 http://127.0.0.1:5000
```

## 功能流程

1. **项目与色版**:建立 2～8 块色版,导入底稿;每版可设油墨颜色、透明度、区域目标色、最小可刻线宽、3 个套准标记、纸张方向与干燥规则。
2. **区域勾勒**:在画布上逐点单击勾勒各版封闭区域,可设区域级目标色。
3. **合成预览与检测**:按版序合成预览,一键检测露白、非预期叠色、过窄线条、越出纸面。
4. **套准模拟**:拖动(Alt+拖动旋转)模拟各版横纵偏移与旋转,实时列出各目标区域的最大错位。
5. **试印校准**:录入 3 个标记的设计/实测坐标,最小二乘解算平移+旋转+统一缩放修正,可叠加修正前后轮廓,并把修正应用回色版;记录入库。
6. **版序优化**:锁定部分版的印次或修正,枚举剩余版序,按目标混色误差 → 清墨换色次数 → 干燥等待次数排序;选定方案入库并回写版序。
7. **减版刻印流程**:同一块实体木版的连续刻印阶段管理——从项目色版选取纸面/套准标记/区域建立流程,在上一阶段副本中勾画本轮刻除区;阶段滑杆按序叠印预览、逐步高亮新刻区,后端栅格化差分并检测着墨区超出剩余凸面、凸面/连接桥窄于最小线宽、前印次未完成即刻版;确认即冻结来源色版与几何快照,输出镜像刻除图/保留面图/着墨图/操作记录;已印阶段与刻掉区域不可恢复,改草稿即时标失效后续阶段。
8. **输出**:逐版水平镜像转印图(PNG)与可打印的套准校准页。

## 减版流程的数据与检查

- 每遍顺序:**在剩余凸面(base)上着墨印刷 → 刻掉本轮刻除区 → 交给下一遍的凸面(relief)**。
- 阶段状态:`draft 草稿 → pending 待印(已确认、快照冻结) → printed 已印(记录合格/废张) → locked 锁定`;
  待印可撤回草稿,已印/锁定不可改刻除区,草稿删除后阶段重排。
- 阶段差分在后端按 3 px/mm 栅格化:刻除多边形自动与当前凸面求交(刻在已刻区/木面外忽略),
  窄线/窄桥用方形 8 邻域位域开运算检测(任一方向窄于最小线宽即消失),
  着墨区取色版区域快照与凸面求交,越界面积给出提示。
- 检查项分**阻断**(着墨超出凸面、凸面/连接桥过窄、前一印次未印完即继续刻版)与**提示**(刻除越出木面);
  阻断默认拒绝确认,可在确认风险后强制通过并记入操作记录。
- 阶段保存五张灰度 PNG 掩码(`base/relief/carve/ink/narrow`,SQLite BLOB)供前端叠印与出图;
  来源色版、区域几何、套准标记、油墨、最小线宽、纸面在建流程时整体冻结,色版事后修改不影响流程。

## API 概览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/projects` | 项目列表 / 新建 |
| GET/PUT/DELETE | `/api/projects/<id>` | 项目读写删 |
| POST | `/api/projects/<id>/blocks` | 添加色版(≤8) |
| PUT/DELETE | `/api/blocks/<id>` | 修改 / 删除色版(≥2) |
| POST | `/api/blocks/<id>/regions` | 添加封闭区域 |
| PUT/DELETE | `/api/regions/<id>` | 修改 / 删除区域 |
| POST | `/api/blocks/<id>/trials` | 试印三点解算并记录 |
| GET | `/api/projects/<id>/trials` | 试印记录 |
| POST | `/api/projects/<id>/enumerate` | 枚举版序并排序 |
| GET/POST | `/api/projects/<id>/plans` | 方案列表 / 保存 |
| GET/POST | `/api/projects/<id>/flows` | 减版流程列表 / 从色版建立 |
| GET/PUT/DELETE | `/api/flows/<id>` | 流程读取(含掩码)/ 改名 / 删除 |
| POST | `/api/flows/<id>/stages` | 新建草稿阶段(副本继承当前凸面) |
| PUT/DELETE | `/api/stages/<id>` | 改草稿(后续自动标失效)/ 删草稿 |
| POST | `/api/stages/<id>/confirm` | 确认阶段,冻结快照(可 `force` 跳过阻断项) |
| POST | `/api/stages/<id>/withdraw` | 待印撤回到草稿 |
| POST | `/api/stages/<id>/print` | 记录实际合格印数与废张 |
| POST | `/api/stages/<id>/lock` · `/unlock` | 锁定完成阶段 / 解锁 |
